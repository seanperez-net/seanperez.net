# Loading indicator

M3 Expressive loading indicator: seven Material shapes morphing while they turn, for a wait of
about 200ms to 5s whose progress is unknown. Specs:
https://m3.material.io/components/loading-indicator (specs and accessibility read 2026-11-23).

NEW: e-store has no loading indicator.

## API

| Prop | Default | |
|---|---|---|
| `contained` | false | `primary-container` circle behind an `on-primary-container` shape; default is a `primary` shape alone |
| `size` | 48 | dp, clamped to 24..240 (M3); the shape keeps its 38 : 48 ratio |
| `aria-label` / `aria-labelledby` | — | `role="progressbar"` with a name (M3 accessibility) |

## How it is built

`tokens/components/loading-indicator.css` is GENERATED by `scripts/loading-indicator-shapes.mjs`
from androidx Compose's `MaterialShapes.kt` (SoftBurst, Cookie9Sided, Pentagon, Pill, Sunny,
Cookie4Sided, Oval) and `LoadingIndicator.kt` (650ms per morph, a 4666ms global turn, a quarter
turn per morph). Each shape is resampled to 72 points so `clip-path: polygon()` can interpolate
between them. Do not edit the CSS by hand; change the script and run
`node scripts/loading-indicator-shapes.mjs`.

Reduced motion: no morph; the first shape turns.

## Left out

The determinate Compose variant and pull-to-refresh (Compose only, not in the M3 configurations).

## Proof

- PROOFED 2026-11-23: colours, 48 / 38dp, size range, role and label (M3 pages); timings and
  shape order against the Compose source.
- Measured in Chrome: 48x48, 96x96, contained fill `primary-container`.
- NOT PROOFED: the polygon morph approximates Compose's cubic morph (rounded corners are
  resampled straight segments); compared by eye only. The spring timing is approximated with the
  `expressive-fast-spatial` easing.
